Computer Science & AI

CS & AI 学习

2025 年初起，我在专业课之外系统自学计算机与人工智能。这一页记录我走过的路径、用过的材料， 以及把 Python 用在真实大气科学数据上的实践。

学习路径

自学从“能写对程序”开始，先补算法与系统基础（数据结构、算法、计算机组成、操作系统）， 再学如何把数据变成结论（数据处理、统计分析、机器学习），最后进入深度学习与大模型应用。 全程以“写出来、跑起来、部署上去”为标准，而不是看完视频就算学完。

编程语言与工程基础

Java 全栈

Java 语法与面向对象 → JavaWeb → Spring / MyBatis-Plus / Spring Cloud 微服务， 并以《苍穹外卖》《天机学堂》两个企业级项目实战贯穿； 后延伸至 Spring AI + DeepSeek 的大模型应用开发。

Python 后端

Python 进阶与工程化、FastAPI 从入门到实战、Flask、Celery 异步任务与 RESTful API 设计。

数据库与中间件

MySQL（基础 / 进阶 / 运维）、Redis 缓存与数据结构、Kafka 消息队列、MongoDB。

前端

HTML5 / CSS / JavaScript 基础，Vue 3 与 React 组件化开发，TypeScript，微信小程序开发。

工程化与工具

Linux、Git、Docker、设计模式、正则表达式、HTTP / TCP-IP、Playwright 自动化测试。

数据、机器学习与深度学习

模块主要内容
数据处理与统计分析NumPy、Pandas、Matplotlib；数据的读取、清洗、聚合与可视化。
机器学习回归、分类、聚类与模型评估；scikit-learn 实践，结合吴恩达 CS229 课程。
深度学习与神经网络PyTorch 基础、CNN / RNN / Transformer 结构、训练与调参；结合 CS231n 课程。
自然语言处理文本表示、词向量、注意力机制与预训练语言模型；Transformers 快速入门。
计算机视觉图像分类、目标检测与实例分割；结合本科《计算机视觉》课程与 Mask R-CNN 项目。

大模型与智能体

大模型开发

零基础入门 AI 大模型开发；Prompt Engineering；模型 API 调用与本地部署（Ollama / 量化模型）。

RAG 与 Agent

检索增强生成（RAG）全链路：文档解析、语义分块、向量检索（FAISS）与关键词检索（BM25）融合、重排序与溯源； 基于 LangChain 与 AgentScope 构建工具调用型智能体（ReAct、多工具注册）。

AI 辅助开发

Vibe Coding 项目开发流程；用 AI 辅助编写、调试与重构代码，并沉淀为可复用的工作流。

代码实践 · 大气科学数据处理

把 Python 用在具体的科学问题上，是我检验学习成果的方式。以下主题的脚本均在自己的研究中运行使用， 涵盖数据读取、滤波、诊断与绘图全过程：

  • 降水与对流：GPM 半小时 / 逐日降水的合并、异常计算与 Hovmöller 图、OLR 异常分析。
  • 赤道波动诊断：MJO、Kelvin、MRG、ER 波的滤波，以及涡旋拉伸（vortex stretching）与垂直积分水汽输送（VIMD）计算。
  • 台风 Freddy：路径与强度提取、生成盒区环境场、降水与 850 hPa 风场合成。
  • 风能太阳能资源：年平均风能资源、风速与比湿剖面、SST 及异常场处理。
  • 数值天气预报与统计预报作业：课程作业涉及的资料处理与绘图脚本。
  • 谱分析与相干：调和分析、谱自由度估计、相干谱计算。
